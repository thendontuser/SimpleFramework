Лабораторная работа 2. Аннотации
Цель работы: научиться работать с рефлексией и аннотациями

В ходе выполнения данной лабораторной работы были разработаны:
 - Аннотация @Before - признак того, что методы, помеченные данной аннотацией, выполняются в первую очередь
 - Аннотация @Test - признак того, что методы, помеченные данной аннотацией, выполняются после выполнения методов, помеченных аннотацией @Before
 - Аннотация @After - признак того, что методы, помеченные данной аннотацией, выполняются после выполнения методов, помеченных аннотацией @Test
 - Класс TestArithmetical - класс с набором методов, помеченных разработанными аннотациями
 - Перечисление MathOperation - перечисление арифметических операций
 - Класс TestRunner - класс, обрабатывающий разработанные аннотации и запускающий методы класса TestArithmetical
 - Класс Main - запускает TestRunner
